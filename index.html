Installation Guide

  1. 1
    Download the compiled deep_glow.wasm file from the Releases page[cite: 5].
  2. 2
    Directly in EffectCraft: Go to Effect → Load Effect Plug-in... and select the .wasm file[cite: 5].
  3. 3
    Manual Installation: Move deep_glow.wasm to your platform's Plug-ins directory[cite: 5]:
🐧 Linux: ~/.config/effectcraft/Plug-ins/[cite: 5]
🍎 macOS: ~/Library/Application Support/EffectCraft/Plug-ins/[cite: 5]
💻 Windows: %APPDATA%\EffectCraft\Plug-ins\[cite: 5]
